# 🤖 Minicurso: Engenharia de Prompt para Engenheiros de Software - USP ESALQ

## 📌 Sobre o projeto

Este repositório contém os laboratórios práticos desenvolvidos durante o **Minicurso de Engenharia de Prompt para Engenheiros de Software**, integrante do programa de **MBA em Engenharia de Software da USP ESALQ**.

O curso aborda a integração entre **Engenharia de Software tradicional** e as novas possibilidades oferecidas pelas **IAs Generativas (LLMs)**, explorando como utilizar inteligência artificial como ferramenta de apoio ao desenvolvimento de software.

A proposta central é capacitar o desenvolvedor a atuar como **piloto do processo de desenvolvimento**, utilizando a IA como **copiloto**, mantendo sempre a validação humana, análise crítica e responsabilidade técnica sobre os resultados.

---

## 🚀 Sobre o curso

Durante o minicurso foram explorados conceitos fundamentais de:

* Engenharia de Prompt aplicada ao desenvolvimento
* Uso eficiente de modelos de linguagem (LLMs)
* Criação de prompts estruturados
* Validação de código gerado por inteligência artificial
* Análise crítica de respostas de IA
* Aplicação prática de IA no ciclo de desenvolvimento de software

---

## 📂 Projetos desenvolvidos

O repositório está organizado em **6 módulos práticos**:

### 📊 Projeto 1 - Exibição de Dados

Fundamentos de manipulação do **DOM**, eventos e interação com elementos HTML utilizando **JavaScript puro**.

### 🧮 Projeto 2 - Calculadora

Implementação de lógica condicional, operadores matemáticos e processamento de dados.

### 📝 Projeto 3 - Lista Dinâmica

Manipulação de arrays e criação dinâmica de elementos HTML através do JavaScript.

### 🐞 Projeto 4 - Debug

Prática de revisão crítica de código utilizando LLMs para identificação e análise de possíveis erros.

### 📚 Projeto 5 - Documentação

Aplicação de técnicas de engenharia de prompt para geração automatizada de documentação técnica.

### 🔐 Projeto 6 - Prototipagem

Desenvolvimento de um sistema de cadastro funcional com validações e preocupação com segurança.

## 🧠 Competências desenvolvidas

### 🎯 Anatomia do Prompt

Aplicação dos elementos:

* Papel
* Tarefa
* Restrições
* Formato esperado

para criação de comandos mais precisos e eficientes.

### 🔍 Validação de Código

Análise de códigos gerados por IA buscando identificar:

* Falhas de lógica
* Problemas de segurança
* Vulnerabilidades como XSS
* Melhorias de implementação

### 💡 Pensamento Crítico

Compreensão da natureza probabilística dos LLMs, evitando dependência cega das respostas geradas pela inteligência artificial.

### 🌐 Desenvolvimento Web

Prática com:

* HTML
* CSS
* JavaScript puro
* Manipulação de interfaces dinâmicas
